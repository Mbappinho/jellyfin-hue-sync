# Recording a real demonstration

No physical lamp demonstration video is included in the initial source publication. An interface screenshot or generated animation is not evidence of lamps matching a film.

## Interface preview

[The interface screenshot](images/control-ui.png) was captured from the real web page served locally with empty fixture status. No bridge was paired and no lamps were contacted. This is visual UI evidence only, not film-synchronization evidence.

## Suggested 30-second recording

1. Use a self-created or appropriately licensed test clip with clear warm/cool transitions.
2. Frame the real TV and the actual lamps in the same camera shot.
3. Show the lamps before playback, then launch the video without touching the web UI.
4. Show a color transition, pause/resume, and stop the video.
5. Show the lamps returning to their pre-playback settings.

Avoid identifiable faces, account information, API keys, private addresses and unlicensed movie footage. Declare any cuts or speed changes; do not imply measured frame accuracy from a promotional edit.
